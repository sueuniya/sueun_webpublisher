ABOUT

함께 고민하고,
더 나은 방법을 찾아갑니다.

프로젝트의 완성도를 높이는 과정에는 구현 역량뿐 아니라 소통과 개선을 위한 고민이 필요하다고 생각합니다.

01

원활한 소통과 협업

기획자, 디자이너, 개발자뿐 아니라 해외 퍼블리셔와도 협업하며 작업 기준과 방향을 조율해 왔습니다. 서로 다른 환경에서도 명확한 가이드와 피드백을 통해 프로젝트의 완성도를 높였습니다.

02

사용성을 고려한 UI 구현

fullPage.js, Swiper.js 등을 활용한 인터랙션 구현부터 반응형 화면 최적화까지, 서비스의 목적과 디자인 의도를 고려해 UI를 구현합니다.

03

효율적인 작업 환경과 지속적인 개선

공통 컴포넌트와 마크업 구조를 고민하고, GitHub Copilot과 Cursor 등 AI 도구를 활용해 반복 작업과 코드 개선의 효율을 높일수 있습니다.
